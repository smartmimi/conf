# 时间卡

由 JSBox 小组件迁移至 Scripting，完全本地计算，无需联网。

## 使用

1. 运行「时间卡」，可预览小、中、大号组件。
2. 在主屏幕添加 Scripting 小组件，编辑组件并选择「时间卡」。推荐中号。
3. 如需提醒，运行脚本选择「开启 / 更新未来 8 个节日提醒」，允许系统通知。节日当天早上 6 点发送；当天已经过 6 点则跳过本次提醒。再次运行此项会替换本脚本的待发送提醒。提醒不会无限自动续订，请在最后安排日期之前再次更新。
4. 「关闭节日提醒」只取消本脚本的待发送提醒。

## 布局

- 小号：公历日期、最近节日倒数、农历与星座或节气。
- 中号：左侧最近节日，右侧后续四个节日，顶部显示农历和干支生肖。
- 大号：最近节日及后续五个节日。
- 暖白／炭黑背景随系统外观变化；陶土色突出倒数。适配系统着色和透明背景。
- 节日当天显示「今天」。每天零点后一分请求刷新，实际刷新由 iOS 调度。

## 迁移说明

- 移除 `$widget`、`$color`、`$font`、`$cache`、`$push` 等 JSBox 专用接口。
- `widget.tsx` 使用 Scripting 原生布局；`index.tsx` 提供预览与可选本地提醒。
- `calendar.js` 保留原脚本的 JJonline 农历算法及署名；节日由 `model.ts` 按公历固定日期、农历转换及清明节气计算生成，无需维护静态节日表。农历和节气计算支持 1901—2099 年。
- `model.ts` 自动计算后续年份节日，解决原列表结束后的越界。农历和清明使用原算法，当前对 1901—2099 年开放；范围外仍提供固定公历节日，隐藏农历信息。
- 日期差按当地日历日计算，不包含今天，避免夏令时带来的时长误差。

## 验证

三种尺寸已运行截图检查。`model.test.ts` 验证节日当天与次日切换、跨年、闰年、夏令时日期差、计算出的农历节日、固定日期回归及 2026—2032 年节日数量与去重。通知功能通过类型检查，未在开发验证过程中安排真实通知。
